# NEUQ emblem asset

`neuq-emblem.png` is the official Northeastern University at Qinhuangdao seal,
downloaded unchanged from the university's official seal page on 2026-09-23.

- Official page: https://www.neuq.edu.cn/info/1204/1443.htm
- Original PNG: https://www.neuq.edu.cn/__local/C/F3/21/FE9F31B603764AA15F9F432A3C6_2BB0CB0D_111BC.png

It is bundled locally for the Web UI identity mark and browser favicon; the mark
remains the university's property.
